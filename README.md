### 🧡 [Beyond the Sidelines](https://beyond-the-sidelines.com)
A recovery app I built after I tore my ACL & meniscus and had surgery. It pairs physical therapy exercises with private journaling, gives clinics a dashboard to track patients between visits, real-time patient/therapist messaging, and a mental wellness mode (breathing, grounding, journaling). Live, with real users.

**Built with:** React · Firebase (Auth + Firestore) · PWA · Capacitor (iOS)

**Right now:** getting it into physical therapy clinics 🏥
